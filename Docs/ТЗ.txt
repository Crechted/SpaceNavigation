Space Navigation Simulation
 Ключевые требования
1. Необходимо реализовать упрощённую симуляционную среду в Unreal Engine 5.
2. В среде присутствует планетарная система (звезда и набор небесных тел), параметры и начальные положения которых генерируются процедурно на основании заданного random seed.
3. Космический аппарат имеет физические характеристики, двигатель, запас топлива и cтартовые параметры. Параметры аппарата и миссии должны задаваться через конфигурацию сценария и не должны быть захардкожены в логике симуляции или планировщика.
4. Цель аппарата - переместиться с заданной начальной орбиты стартового тела(Starting Body) до внешней границы системы(Target Distance / System Boundary).
5. Для перемещения аппарат может использовать собственную тягу и гравитационные манёвры вокруг небесных тел.
6. Необходимо реализовать систему планирования маршрута, которая выбирает последовательность манёвров на основании выбранного критерия оптимальности.
7. Параметры симуляции, конфигурация аппарата и небесных тел должны быть отделены от логики симуляции.
8. Необходимо предусмотреть возможность расширения системы новыми типами небесных тел.
9. Архитектура должна использовать C++ и Blueprint в соответствии с назначением каждого инструмента.

 Критерии оптимальности
Система планирования маршрута должна поддерживать многокритериальную оптимизацию. Критерии оптимальности и их относительный приоритет должны задаваться через конфигурацию и не требовать изменения исходного кода алгоритма планирования. Предусмотреть следующие режимы оптимизации:
1. Fuel Efficient (минимальный расход топлива). 
Цель - найти допустимый маршрут с минимальным суммарным deltaV, необходимым для выполнения всех манёвров.
Основной критерий: TotalCost = TotalDeltaV
2. Time Efficient (минимальное время полёта). 
Цель - минимизировать время от начала миссии до достижения внешней границы системы.
Основной критерий: TotalCost = FlightTime
Примечание: маршрут должен удовлетворять ограничениям аппарата по топливу, тяге и другим параметрам миссии.
3. Balanced (сбалансированная оптимизация).
Цель - учитывать одновременно расход топлива, время полёта и риск выполнения маршрута.
Итоговая стоимость маршрута рассчитывается как взвешенная сумма нормализованных критериев: 
TotalCost = WFuel * FuelCost + WTime * TimeCost + WRisk * RiskCost где:
1. WFuel - вес расхода топлива;
2. WTime - вес времени полёта;
3. WRisk - вес риска;
4. FuelCost - нормализованная оценка расхода топлива;
5. TimeCost - нормализованная оценка времени;
6. RiskCost - нормализованная оценка риска.

 Конфигурация сценария
Режим оптимизации и значения весов должны задаваться через конфигуратор сценария.
Для режимов FuelEfficient и TimeEfficient соответствующий критерий имеет максимальный приоритет. Для режима Balanced используются заданные пользователем веса.
Пример конфигураций:
Fuel Efficient:
    FuelWeight = 1.0    TimeWeight = 0.0    RiskWeight = 0.0
Time Efficient:
    FuelWeight = 0.0    TimeWeight = 1.0    RiskWeight = 0.0
Balanced:
    FuelWeight = 0.6    TimeWeight = 0.3    RiskWeight = 0.1

Конфигурация не должна быть жёстко связана с конкретным алгоритмом поиска маршрута. Предполагается возможность добавления новых критериев или изменения их весов без существенной переработки системы планирования.
Параметры аппаратра задаются в конфигураторе и фиксированы на протяжении конкретной миссии, за исключением расхода топлива и, соответственно, текущей массы.

Начальное положение аппарата (Starting Body) также задаётся в конфигураторе и не может быть внешним/самым удалённым телом системы.

 Риск выполнения манёвров
При оценке маршрута необходимо учитывать риск выполнения гравитационных манёвров. Риск должен отражать насколько траектория манёвра близка к недопустимым условиям и насколько она чувствительна к ошибкам выполнения.
В рамках задания допускается упрощённая модель оценки риска. Рекомендуется учитывать:
* минимальное расстояние до небесного тела; 
* относительную скорость при сближении; 
* допустимую погрешность параметров манёвра; 
* доступный запас топлива для коррекции траектории. 
Значение риска должно быть нормализовано в диапазон [0; 1], где 0 соответствует минимальному, а 1 - критическому риску.
Столкновение с небесным телом, превышение максимально допустимой скорости или нарушение других жёстких ограничений должны приводить к признанию манёвра недопустимым, а не просто увеличивать его стоимость.

 Условия, ограничения и свойства объектов
Параметры план.системы
* Random Seed - начальное значение для генерации системы. Один и тот же seed должен позволять воспроизвести одну и ту же конфигурацию.
* Number of Planets - количество генерируемых небесных тел.
* Min Orbital Radius - минимально допустимый радиус орбиты при генерации планет.
* Target Distance / System Boundary - расстояние, достижение которого считается выходом аппарата за пределы системы.
Внешняя граница системы может быть определена одним из способов:
** фиксированное значение, например Target Distance = 120 AU;
** относительное значение, например:
System Boundary = K * Orbital Radius самого удалённого тела.
Центральное тело:
* Mass - масса тела.
* Radius - размер тела.
Планеты:
* Mass - масса тела, определяет силу его гравитационного воздействия.
* Radius - определяет размер тела и допустимое сближение.
* Orbital Radius - радиус орбиты относительно центральной звезды.
* Orbital Velocity - cкорость движения тела по орбите (вычисляемая величина); 
* Initial Orbital Position - начальная фаза / положение тела на орбите.
* Orbital Inclination - наклон орбиты относительно базовой плоскости (опционально).
* Sphere of Influence - область, в пределах которой гравитационное влияние тела считается значимым (опционально; может быть фиксированной или вычисляемой величиной).
Параметры аппарата
* DryMass - сухая масса аппарата. При расходовании топлива масса аппарата должна уменьшаться.
* Fuel Mass / Fuel Amount - доступное количество топлива.
* Current Spacecraft Mass — вычисляемая величина.
* Max Thrust - максимальная тяга двигателя.
* Fuel Consumption / Specific Impulse - расход топлива в ед.времени при работе двигателя или удельный импульс.
* Starting Body - небесное тело, относительно которого задаётся старт аппарата.
* Starting Orbit Radius - радиус начальной орбиты аппарата вокруг стартового тела.
* Initial Orbital Position - начальная фаза аппарата на стартовой орбите (если положение не определяется иным способом).
* Initial Spacecraft Velocity - начальная скорость аппарата относительно стартового тела.
Вычисляемые параметры
* Initial Spacecraft Velocity;
* Current Spacecraft Mass;
* Gravitational Acceleration
* Orbital Velocity;
* Sphere of Influence;
Ограничения.
* Аппарат не должен сталкиваться с небесными телами.
* Аппарат не должен пересекать поверхность небесных тел. (минимальное расстояние от центра тела до аппарата должно быть не меньше его радиуса).
* Аппарат не может израсходовать больше доступного количества топлива.
* При наличии ограничения по времени: Flight Time <= Max Flight Time.
* Миссия считается успешно завершённой при достижении Target Distance.
